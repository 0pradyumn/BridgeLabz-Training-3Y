Q9. Responsive Design Principles Summary

Fluid Layouts

Use percentages and flexible units so layouts stretch and shrink with the screen.

.container {
  width: 90%;
  max-width: 1100px;
}

Flexible Media

Images and videos scale inside their containers and never overflow.

img {
  max-width: 100%;
  height: auto;
}

Breakpoints

Media queries change the layout at specific screen widths.

@media (max-width: 600px) {
  .grid { display: block; }
}
