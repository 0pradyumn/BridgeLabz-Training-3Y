How to run
----------
1. Extract the ZIP file.
2. Open any question folder.
3. Double-click index.html, or open it in a browser.
4. Each question has its own index.html and style.css.

Notes
-----
- Every question has separate HTML and CSS files.
- No JavaScript or external CSS frameworks are used.
- Layouts use Flexbox and/or CSS Grid and include responsive media queries.
- Some sample photographs load from Unsplash and therefore need an internet connection.
- Product gallery cards use emoji illustrations, so they do not depend on external product images.
- Replace sample names, text, prices, and image URLs if your instructor expects personal details.
